# Roadmap (living)

This is a lightweight roadmap for the portfolio. Sections can ship incrementally.

## Phase 0 — Maintain baseline (now)
- Keep current routes working: `/`, `/about`, `/experience`, `/education`, `/projects`
- Ensure theme + language selector remain stable
- Improve copy and content without large refactors

## Phase 1 — Content completeness
- About: narrative + values + short bio
- Experience/Education: consistent layout and timelines
- Projects: real project cards with links, tech stack, outcomes
- Add “Now” / “Currently” section (optional)

## Phase 2 — Blog MVP (local MDX)
- Decide MDX rendering approach (ADR required)
- Add blog index and post pages
- Add basic SEO metadata for posts
- Add tags and simple filtering (optional)
- Add RSS feed (optional)

## Phase 3 — Polish & SEO
- Metadata review across pages
- OpenGraph images strategy (ADR if non-trivial)
- Sitemap + robots
- Performance pass (Lighthouse)

## Phase 4 — Analytics & iteration
- Define key interactions to track (navbar, project outbound clicks, language/theme toggles)
- Ensure production analytics is robust; keep dev logging clean
